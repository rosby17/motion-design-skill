# Narration et script : ce qui fait qu'une vidéo convertit

La voix commande tout le montage : un bon script fait 70 % de la vidéo. On l'écrit AVANT de penser aux images.

## Règles qui valent pour toutes les vidéos
- **Une idée par phrase**, une phrase par scène (1 à 3 s de temps fort). Phrases courtes, rythme parlé.
- **Tout ce qui compte est dit ET montré** : une info seulement écrite à l'écran est perdue (le client l'a réclamée à la voix).
  Inversement, une info dite (numéro, adresse, prix) reste affichée assez longtemps pour être lue.
- **Ne vendre que ce qui existe** : chaque promesse correspond à une vraie fonction, une vraie page, une vraie capture. Aucun chiffre
  inventé (élèves, ventes, revenus), aucune promesse de gains : les régies publicitaires refusent, et le client perd confiance.
- **Le brief fait foi** : un flyer, une page de vente ou un message du client est le brief complet. Lister TOUT ce qu'il contient
  (offre, prix, liste, promesses, contacts, adresse, horaires, slogan) et vérifier que chaque élément est dit OU montré.
- **Signaler ce qui est inventé** pour la démonstration (chiffres d'exemple dans une interface, conversation fictive, maquette).
- **Écrire pour l'oreille** : nombres en lettres, sigles épelés (« P V syst », « C F A »), marque écrite comme elle se prononce,
  noms de lieux tels que les gens du pays les disent (un quartier dont le N initial ne se prononce pas s'écrit sans N pour la voix,
  mais garde son orthographe à l'écran). Numéros groupés comme on les lit.
- **Points de suspension** pour une respiration, « ! » pour l'énergie, virgules pour poser le rythme.

## Pub de lancement (SaaS, produit) : le moule en 10 temps
Analyse d'une pub de référence qui convertit (≈ 55 s) :

| Temps | Rôle | Exemple de forme |
|---|---|---|
| 1 | **Accroche-question** : le rêve du client, pas le produit | « Et si votre activité pouvait enfin travailler pour vous ? » |
| 2 | **Révélation + cible** : nom, catégorie, pour qui | « Découvrez X, la plateforme … pensée pour … » |
| 3-5 | **Trois bénéfices, même moule** (règle de trois) | « Besoin de … ? X le fait. » + preuve (chrono, interface) |
| 6 | **Ampleur** : énumération rapide puis « tout en un » | « Commandes, paiements, livraisons… Tout est centralisé. » |
| 7 | **La douleur rayée** | « Plus besoin de tout faire ~~manuellement~~. » |
| 8 | **Partage des rôles** : vous / nous | « Vous avez le produit. X construit. » |
| 9 | **Signature** : nom + catégorie possédée | « X, l'IA des … » |
| 10 | **Slogan final en 3 temps de 2 mots**, tenu à l'écran | « Vous branchez. X crée. Vous vivez. » |

Principes : questions courtes qui découpent la vidéo en chapitres ; chaque fonction montrée par l'interface RÉELLE ; une preuve
chiffrée honnête (un chrono, une capture) ; fin posée (logo + signature + slogan tenu 3 s) ; appel à l'action concret (essai, site).

## Spot client (formation, santé, école, commerce)
1. Accroche sur le besoin du public (« Mesdames… », « Vous voulez… ? »).
2. L'offre : nom, ce qu'on obtient, pour qui (dire le public cible).
3. Le contenu, élément par élément (examens, modules, filières), chacun avec SON visuel vivant.
4. Les promesses / garanties du brief.
5. Le prix (compteur, mise en valeur) et l'avantage limité s'il existe (« les 15 premiers inscrits »).
6. Comment agir : appel / WhatsApp / site, numéro qui s'allume au mot, adresse et horaires.
7. Logo + slogan.

## Vidéo de présentation (plateforme, service, agence)
Suivre le **parcours du visiteur** : le problème (ce qu'il perd aujourd'hui) → ce qu'il obtient (une vraie capture par promesse) →
comment ça marche, étape par étape → la communauté / l'accompagnement → les preuves (avis vérifiés) → le prix et ce qu'il comprend →
la mission → l'appel à l'action. Ne nommer ni clients ni projets sans accord : raconter l'histoire du client type.

## Vidéo longue YouTube (éducation, astuces, actualité)
Prose continue, 5 temps (accroche + promesse, contexte, contenu en parties numérotées, cas concret, conclusion + appel à s'abonner).
Vérifier chaque chiffre sur des sources sérieuses avant de le dire ; cas illustratifs présentés comme fictifs (« imagine… ») ;
jamais de diagnostic ni de promesse miracle sur la santé. Voir `videos-longues.md` pour le montage.

## Retours sur le script
Noter les retours mot pour mot, puis réécrire. Exemples de retours qui améliorent un script : élargir la cible, montrer l'orchestration
plutôt que « l'outil fait tout », ajouter l'identité de la marque, retirer les gains chiffrés risqués, finir sur un slogan en 3 temps.
